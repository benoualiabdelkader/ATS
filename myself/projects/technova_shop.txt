LANGUAGES: HTML (75%), JavaScript (21.3%), CSS (3.7%)

--- TECH STACK ---
Frontend: HTML5, CSS3, Vanilla JavaScript (ES6+)
Styling: Tailwind CSS v3.x, Custom CSS Variables, Animations
Typography: Google Fonts (Inter)
APIs: FakeStore API (product catalog), Unsplash API (dynamic imagery)
Data Persistence: Browser localStorage (cart, user data, orders)
Architecture: Multi-page frontend with Single-Page App views inside index.html

--- KEY FEATURES BUILT ---
1. Full E-Commerce Product System
   - Integrated FakeStore REST API to fetch and render a live product catalog dynamically.
   - Built advanced search with intelligent autocomplete suggestions (laptop, phone, headphones, watch, tablet).
   - Implemented advanced filtering: price range filter, category filter, and multiple sorting options (price, rating, etc.).
   - Product modals with detailed information overlay and image zoom.

2. Shopping Cart & Checkout
   - Full shopping cart with add/remove/update quantity and persistent localStorage storage.
   - Secure checkout process with multi-step form validation.
   - Order history tracking — orders saved locally with full details and status.

3. User Account Management
   - User registration and login system with demo login (one-click demo account access).
   - Profile management with editable user information.
   - Account settings with user preference controls.
   - Session persistence via localStorage.

4. Dynamic Image Slider
   - Integrated Unsplash API for dynamically loaded hero banner images (auto-refresh every 5 seconds).

5. Multi-View SPA Architecture (inside index.html)
   - Shop View, Cart View, Checkout View, Profile View, Orders View, Settings View, About View, Contact View — all within a single page using JavaScript view switching.

6. Multi-Page Standalone Pages
   - Login (login.html), Signup (signup.html), Promotions (promotions.html), Support (support.html), Privacy (privacy.html), Terms (terms.html).

7. UI/UX & Design System
   - Modern professional dark theme with Indigo (#6366f1) and Emerald (#10b981) color system.
   - Toast notification system (3-second auto-dismiss) for real-time user feedback.
   - Responsive layout: 4-column grid (desktop 1024px+), 3-column (tablet 768px+), 1-2 column (mobile <768px).
   - Hamburger menu navigation for mobile.
   - Loading states and comprehensive API error handling with fallback states.
   - ARIA labels and keyboard navigation for accessibility compliance.

8. Data Architecture
   - localStorage keys: techNovaUser, techNovaCart, techNovaOrders.
   - Configurable constants: ITEMS_PER_PAGE=20, SLIDER_INTERVAL=5000ms, TOAST_DURATION=3000ms.

--- ARCHITECTURE ---
- index.html: Main SPA hub with all view states controlled by JS
- script.js: Core application logic (API calls, cart, auth, views, search, filters)
- style.css: Custom animations and CSS variables extending Tailwind
- login.html / signup.html: Auth pages
- promotions.html / support.html / privacy.html / terms.html: Standalone informational pages
- images/: Local static assets
