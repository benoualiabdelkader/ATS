--- TECH STACK ---
Frontend: HTML5, CSS3 (Tailwind CSS), Vanilla JavaScript
External API: The Movie Database (TMDB) API v3
Icons: Lucide Icons
Authentication: Google OAuth 2.0 + Local email/password auth
Design: Responsive / Mobile-first, Light/Dark theme toggle
Server: Static file serving (serve npm / Apache / Nginx compatible)

--- KEY FEATURES BUILT ---
1. TMDB API Integration
   - Integrated The Movie Database (TMDB) API v3 to fetch and display a vast library of movies and TV shows.
   - Built detailed content pages (details.html) showing overview, cast, trailers, and recommendations for each title.
   - Implemented category browsing and dynamic content rendering from the API.

2. Search Functionality
   - Built a full search system (search.html + js/search.js) allowing users to find specific movie and TV show titles instantly.
   - Integrated the TMDB search endpoint with real-time query handling.

3. Favorites & Watchlist Management
   - Built a favorites system (favorites.html + js/favorites.js) for users to mark and manage their favorite content.
   - Implemented a personalized watchlist to track titles to watch later.

4. User Authentication
   - Implemented dual authentication: local email/password login system and Google OAuth 2.0 integration.
   - Configured Google Cloud Console OAuth 2.0 Client IDs (Web application type) with authorized origins and redirect URIs.
   - Built login/signup page (login.html) and user profile page (profile.html).

5. Multi-Language Support
   - Implemented a language switching module (js/language.js) supporting Arabic and English interfaces.

6. Theme Toggling
   - Built a light/dark theme toggle system for personalized viewing experience.

7. Responsive Design
   - Mobile-first responsive layout using Tailwind CSS ensuring seamless experience across all devices.

--- ARCHITECTURE ---
- index.html: Main entry point (browsing/discovery interface)
- details.html: Individual movie/TV show detail page
- search.html: Search results page
- favorites.html / favorites-new.html: User favorites pages
- profile.html: User profile management
- login.html: Authentication page
- js/app.js: Core application logic + TMDB API integration
- js/auth.js: Authentication (local + Google OAuth)
- js/favorites.js: Favorites and watchlist management
- js/language.js: Language switching functionality
- js/search.js: Search logic
- css/style.css: Custom CSS styles (on top of Tailwind CSS)
