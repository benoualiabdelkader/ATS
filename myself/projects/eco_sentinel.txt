--- WHAT THE SYSTEM DOES ---
Monitors water quality in aquatic ecosystems using AI/ML.
Analyzes sensor data (turbidity, dissolved oxygen, and other environmental parameters).
Predicts pollution status in real time using a trained SVM RBF model.
Delivers results through a cinematic Glassmorphism web interface with bilingual Arabic/French support.

--- KEY FEATURES BUILT ---
1. SVM Machine Learning Model (RBF Kernel)
   - Trained and evaluated an SVM RBF classifier achieving 98% accuracy in detecting water pollution states.
   - Processed environmental sensor data (turbidity, dissolved oxygen levels) from a custom CSV dataset.
   - Model training and evaluation separated in train_eco_models.py / train_and_evaluate.py scripts.

2. Streamlit Web Interface (Cinematic Glassmorphism)
   - Built an eco_interface.py Streamlit application with modern Glassmorphism visual design using Tailwind CSS and Custom CSS.
   - Interactive simulator with real-time sliders allowing users to adjust sensor parameters and get instant pollution predictions from the SVM model.
   - Bilingual Arabic/French interface demonstrating multilingual UI development.
   - Optimized with Streamlit caching for minimal resource consumption.

3. Dataset Generation
   - Custom dataset generated programmatically (generate_dataset.py, generate_eco_dataset.py) for training the pollution detection model.

4. Academic Documentation
   - Formal LaTeX PDF project report (rapport_sentinelle_ecologique.pdf).
   - Slide content (slides_content.md) for presentation.
   - Full French-language academic project documentation.

5. One-Click Windows Launcher
   - run_interface.bat for streamlined Windows execution.
