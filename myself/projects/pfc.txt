--- TECH STACK ---
Frontend Framework: Nuxt.js 3 (Vue 3, TypeScript)
Languages: Vue (82.3%), JavaScript (15.4%), TypeScript (1.4%)
Styling: SCSS / CSS (custom theming, dark mode)
UI Libraries: Bootstrap (via bootstrap.client.ts plugin), Vue Toastification
Search Engine: MeiliSearch (full-text search integration)
Database: MongoDB (via Mongoose models: Article, User)
Email Service: Gmail SMTP (contact page implementation)
External APIs: NewsAPI, Mediastack API, YouTube Data API
Authentication: JWT-based auth with role-based access control (RBAC)
Deployment: Nuxt production build with SSR/SSG support

--- KEY FEATURES BUILT ---
1. News Aggregation Platform
   - Integrated Mediastack API and NewsAPI to fetch and display real-time news by category.
   - Built category-based news browsing with dynamic routing (/news/[category]).
   - Implemented live news section with YouTube live stream integration.
   - Podcast section embedded within the main page.

2. Full Authentication System
   - Built complete auth flow: user registration, login, logout, and password confirmation.
   - Implemented role-based middleware (auth.js, roleAuth.js) to protect routes.
   - Admin user management with the ability to ban, delete, change roles, and upgrade users.

3. Article & Community System
   - Community articles: creation, editing, deletion with full CRUD API.
   - Article card display with author info, category tagging, and like system.
   - Article comments handler via server middleware.
   - ArticleEditor.vue for rich text content creation.
   - Delete confirmation modal for safe content management.

4. Advanced Search
   - Integrated MeiliSearch for full-text search across articles and news.
   - Built SearchBar and SearchModal components for instant search UX.

5. ChatBot Integration
   - Implemented an AI-powered ChatBot component accessible across all pages.
   - Added chatbot via composables and plugin architecture.

6. Newsletter Subscription
   - Built newsletter subscription feature with API backend integration.

7. Contact Page
   - Contact form with Gmail SMTP backend integration for real email delivery.

8. UI/UX & Design
   - Implemented full dark/light theme switcher (color-mode.css).
   - Responsive design with SCSS (main.scss) and Bootstrap layout system.
   - HeroCarousel for featured content on homepage.
   - Dynamic navigation header (AppHeader.vue) and footer (AppFooter.vue).

--- ARCHITECTURE ---
- Client-side: Nuxt.js pages + components + composables pattern
- Server-side: Nuxt server API routes (/server/api/) for REST endpoints
- Database Layer: MongoDB models (Article.js, User.js) via mongodb.js utility
- Auth Middleware: Global server middleware (auth.global.js) protecting all API routes
- State Management: Vue composables (useAuth.js, useArticles.js, useNotifications.js, userManagement.js)
