--- TECH STACK ---
Runtime: Node.js (v18+)
Backend Framework: Express.js
AI Engine: Google Gemini 1.5 Flash (via @google/generative-ai SDK)
Frontend: HTML5, CSS3 (Grid/Flexbox), Vanilla JavaScript
Logging: Combined + error log system
Security: Input validation, environment variable API key management (.env)
Deployment: npm start / Express static file serving

--- KEY FEATURES BUILT ---
1. AI-Powered News Chatbot
   - Built a real-time news chatbot powered by Google Gemini 1.5 Flash model.
   - Designed custom system instructions (specialized prompts) to focus the AI specifically on news assistance and analysis.
   - Covers 8 news categories: World, Technology, Sports, Entertainment, Business, Health, Science, Politics.

2. REST API Backend (Express.js)
   - Designed and implemented a POST /chat API endpoint accepting user messages and returning Gemini AI-generated news responses.
   - Built comprehensive static file routing: /, /app, /dashboard, /about, /contact, /status, /help.
   - Implemented proper error handling: 400 (invalid input), 500 (server error), custom 404 page.

3. News Capabilities
   - Real-time news summaries and updates across multiple categories.
   - AI-assisted fact-checking to help users verify information and identify reliable sources.
   - Historical context generation — background information for current events.
   - News summarization: transforms complex news stories into concise, readable summaries.

4. Frontend Interface
   - Modern responsive chat interface (mobile-first design, CSS Grid + Flexbox).
   - Multi-page navigation: Home, App (chat), Dashboard, About, Contact, Help, Privacy, Terms.
   - Bookmarking system for saving news articles and topics.
   - Server status and health monitoring page (/status).
   - Markdown-styled response formatting in the chat interface.
   - User account management page.

5. Security & Observability
   - Secured API key using environment variables (.env), preventing accidental key exposure.
   - Input validation layer against malicious inputs.
   - Logging system: combined.log and error.log for runtime monitoring.

--- ARCHITECTURE ---
- server.js: Main Express server handling routing, API calls, and static file serving.
- public/: Frontend pages (index.html, dashboard.html, about.html, contact.html, etc.)
- public/script.js: Frontend JS handling chat interaction and UI logic.
- public/style.css: Main stylesheet with responsive design.
- Google AI SDK: Integrated @google/generative-ai with custom system prompts for news specialization.
