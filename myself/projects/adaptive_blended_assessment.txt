--- WHAT THE SYSTEM DOES ---
Ingests student writing submissions and learning signals from Moodle assignments.
Runs a multi-stage AI analysis pipeline for student diagnosis and profiling.
Produces student-level profiles, submission diagnostics, unit feedback, and cohort groupings.
Exposes structured results through a REST API backend.
Visualizes outcomes in a React TypeScript frontend for teachers and academic teams.

--- KEY FEATURES BUILT ---
1. AI Analysis Pipeline (WriteLens V2 – Python)
   - Multi-stage AI engine for student writing diagnosis: ingests Moodle data, runs analysis, writes run bundles (JSON artifacts).
   - Groq API integration for LLM-based feedback stylization with strict privacy mode.
   - Privacy-first design: sensitive text fragments sanitized and tokenized before any external LLM calls (GROQ_ENCRYPT_SENSITIVE_TOKENS=true).
   - Fail-closed behavior: if Groq unavailable in strict mode, feedback fails closed (no silent fallback to untrusted text).

2. Backend API Layer (Node.js + Express)
   - REST API surface for run management, archival, and student data serving.
   - Key endpoints: /api/writelens/runs/latest, /runs/:runId/students, /students/:studentId/profile, /submissions, /unit-feedback.
   - Run bundle archival system under backend/data/writelens_archive for preserving analysis history.
   - Feedback provenance fields exposed in all responses for observability.

3. Frontend Dashboard (React + TypeScript + Vite)
   - Teacher-facing web application for visualizing student profiles, risk bands, submission diagnostics.
   - Cohort grouping views and intervention-oriented summaries.
   - Report views and export-oriented data endpoints.

4. Cloud Deployment (Render)
   - Full Docker containerization with Dockerfile and render.yaml configuration.
   - PostgreSQL database integration on Render.
   - 88 production deployments across 3 deployment environments.

5. Security & Privacy Architecture
   - Environment-variable-based secret management (GROQ_API_KEY, GROQ_PRIVACY_TOKEN_KEY).
   - Strict mode enforcement: GROQ_REQUIRE_FOR_FEEDBACK=true.
   - Key rotation policy and per-environment unique privacy token keys.
