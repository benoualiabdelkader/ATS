PROJECT: EdgeQuant - High-Speed LLM Quantization Toolkit
ROLE: Open Source Author
TECH STACK: Python, C++, PyTorch, CUDA, TensorRT, ONNX
DESCRIPTION:
An open-source quantization library that compresses 7B and 13B parameter Transformer models into 4-bit/8-bit precision with minimal perplexity degradation, optimized for deployment on edge devices and consumer GPUs.
KEY ACHIEVEMENTS:
- Gained over 850 GitHub stars and 12,000+ PyPI downloads within 6 months.
- Reduced GPU VRAM footprint by 62% while preserving 98.4% of baseline FP16 model accuracy.
