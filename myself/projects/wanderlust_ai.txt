--- TECH STACK ---
Frontend: HTML5, CSS3, Vanilla JavaScript (ES6+)
Styling: Tailwind CSS, Custom CSS Variables, Font Awesome Icons
Architecture: Single Page Application (SPA) with modular components
AI Engine: Google Gemini API (AI-powered travel recommendations & NLP)
External APIs:
  - Google Gemini API – AI travel recommendations and conversational NLP
  - YouTube Data API – Travel videos and destination content
  - Google Custom Search API – Enhanced destination search capabilities
  - Pexels API – High-quality travel photography
  - OpenWeatherMap API – Real-time weather data integration

--- KEY FEATURES BUILT ---
1. AI-Powered Travel Assistant
   - Integrated Google Gemini API as the core AI engine for smart, personalized travel recommendations.
   - Built a natural language conversational chat interface allowing users to describe travel preferences and receive intelligent itinerary suggestions.
   - Implemented context-aware planning — the AI generates recommendations based on user input (destination, budget, duration, interests).

2. Rich Destination Discovery
   - YouTube Data API integration to fetch and display destination-specific travel videos and guides.
   - Pexels API integration for high-quality destination photography rendered dynamically in the interface.
   - Google Custom Search API for enhanced destination search with enriched content.
   - Real-time weather data via OpenWeatherMap API displayed per destination.

3. Comprehensive Travel Planning Tools
   - Built a flight search and comparison feature browsing multiple airlines.
   - Hotel booking section with advanced filtering options (price, rating, location).
   - Itinerary Builder with drag-and-drop interface for organizing trip activities.
   - Trip collaboration feature for group travel planning with multiple participants.

4. Modern UX & Interface
   - Single Page Application (SPA) with smooth animations and page transitions.
   - Responsive, mobile-first design using Tailwind CSS ensuring cross-device consistency.
   - Dark/Light theme toggle for personalized user experience.
   - Intuitive sidebar navigation system.
   - Quick access home dashboard with recent activity and saved favorites.

5. Multi-API Environment Configuration
   - Managed 6 third-party API keys securely via .env environment variables.
   - Modular JavaScript (ES6+) architecture separating concerns cleanly across components.

--- ARCHITECTURE ---
- index.html: Main SPA entry point
- pages/: Multi-page sections (explore, flights, hotels, planning, profile, etc.)
- js/: Modular JavaScript components per feature
- css/: Custom CSS extending Tailwind CSS
- images/: Static image assets
- .env: Secure API key environment configuration
