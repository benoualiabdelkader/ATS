--- KEY FEATURES BUILT ---
1. Multi-Category Portfolio Showcase
   - 24+ professional projects displayed across 5 categories: Web Dev, UI/UX Design, AI Chatbot, Presentation, Voice-Over.
   - Smart instant project filtering by category with JavaScript-powered transitions.
   - Interactive project modals with descriptions, technologies used, and live links.

2. Dual Theme System
   - Sophisticated dark/light mode toggle with smooth CSS transitions and localStorage user preference persistence.

3. Certifications Gallery
   - Swipeable carousel with 12+ professional certifications displayed at high resolution.
   - Zoom functionality for detailed certificate viewing.

4. Voice-Over Audio Portfolio
   - Custom-built audio player with playback controls and download options for voice-over work.

5. Performance & PWA
   - Progressive Web App (PWA) with Service Worker (sw.js) for full offline capability.
   - Lighthouse scores: Performance 98/100, Accessibility 95/100, Best Practices 100/100, SEO 100/100.
   - First Contentful Paint <0.8s, Time to Interactive <1.2s.
   - Lazy loading for progressive image delivery.

6. Accessibility
   - WCAG 2.1 AA level compliance: full keyboard navigation, ARIA labels, semantic HTML, high contrast color schemes.

7. Contact System
   - Contact form with real-time validation and submission handling.

8. Fluid Animations
   - Scroll-triggered animations, hover effects, and micro-interactions across all sections.
   - Custom animated hourglass loading screen on initial load.
   - Responsive grid: Desktop (1920px+), Tablet (768px+), Mobile (320px+).
