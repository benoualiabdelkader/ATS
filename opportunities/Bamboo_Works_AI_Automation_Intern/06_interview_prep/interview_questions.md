# Expected Interview Questions & STAR Answers

### Q1 (Technical): How have you used Python to automate manual data processing workflows?
**STAR Answer**:
- **Situation**: Manual evaluation of student assessment data was time-consuming and prone to inconsistency.
- **Task**: Build an automated classification and feedback generation pipeline.
- **Action**: Developed the **Adaptive Blended Assessment System** using Python and Random Forest ML algorithms to process inputs and auto-generate reports.
- **Result**: Reduced evaluation processing time to seconds while providing 100% reproducible results.
